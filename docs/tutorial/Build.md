## Build

### Requirements

* Git
* GCC
* CMake
* NASM
* QEMU
* Ninja

### Clone the repository

```
git clone https://github.com/jouderexe/waddle.git
```

### Configure

```
cmake -S . -B build
```

### Compilation
```
cmake --build build
```
### Run

> Running Waddle is not implemented yet.
